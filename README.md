# Study Shuffler

미리 정해둔 학습 유닛을 일간 할당량만큼 뽑아 순서를 섞어 하나씩 제시하는 웹 앱.
실행 시점의 "뭐부터 하지?"를 없애서 편한 공부로 쏠리는 편향을 차단하는 것이 유일한 목적이다.

## 실행

```bash
npm install
npm run dev      # 개발 서버
npm run build    # 타입 체크 + 프로덕션 빌드
```

계정도 서버도 없다. 모든 기록은 브라우저 `localStorage`(`studyshuffler.v1`)에만 남는다.

## 구조

```
src/
  lib/store.ts       데이터 모델 · localStorage · 할당량 산출
  lib/session.ts     셔플 · 지터 · 이월 · 요약 · 주간 집계
  screens/UnitsScreen.tsx    ① 설정 (유닛 CRUD)
  screens/TodayScreen.tsx    ② 오늘 세션 생성
  screens/RunScreen.tsx      ③ 실행
  screens/WeeklyScreen.tsx   ④ 주간 현황
  App.tsx            상태 보관 + 탭 전환
```

## 동작 규칙

**일간 할당량** — `daily` → `round(weekly / 7)` → `round(monthly / 30)` 순으로 먼저 잡히는 값 하나만
채택하고, 셋 다 없으면 그 유닛은 오늘 세션에서 빠진다. 생성 화면에서 오늘치만 줄이거나 늘릴 수
있고, 세션을 시작하면 잠긴다.

**셔플** — 할당량만큼 유닛을 복제해 피셔-예이츠로 섞고, 인접한 두 블록의 `mode`가 같거나 같은
유닛이 연속되면 다시 섞는다. 50회 안에 못 찾으면 (유닛 종류가 물리적으로 부족한 경우) 마지막
결과를 그대로 쓰고 실행 화면에 "유형이 연속될 수 있음" 한 줄을 띄운다.

**지터** — 블록마다 ±2분, 최소 3분. 매번 길이가 미세하게 달라지는 편이 각성 유지에 낫다.

**이월** — 직전 세션에서 스킵한 블록은 다음 세션 맨 앞에 강제로 붙는다 (이월분끼리는 제약 검사
대상이 아니다).

**미래 노출 금지** — 생성 화면은 "무엇을 몇 개"까지만 보여주고 순서는 보여주지 않는다. 실행
화면은 현재 블록 이름·타이머·`3 / 8` 진행 표시만 있고 다음 블록은 어떤 형태로도 드러나지 않는다.

## MVP 제외

푸시 알림 / 사운드 / 계정·서버 동기화 / 다크모드 / 오디오 연동 / 캘린더 연동 / 드래그 앤 드롭
순서 변경 / 태그·검색 / 데이터 내보내기 / 통계 고도화 / 모바일 앱 패키징. 1주일 실사용 후 판단한다.
